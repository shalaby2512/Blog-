# Trolley-X — Mohammed Shalaby's dissertation blog

A static, GitHub Pages-ready research blog focused on the ROS 2 architecture and systems-integration contribution to Trolley-X.

## Publish with GitHub Pages

1. Create a new public GitHub repository (for example, `trolley-x-systems-blog`).
2. Upload `index.html` and the `assets` folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Save. GitHub will display the public URL after deployment.

## Update the blog

- Edit the entries under **Research & engineering log** as work progresses.
- Replace planned language only after the corresponding work or experiment is complete.
- Add measured results and charts once data collection begins.
- Check paper metadata and use the citation style required by the university in the final dissertation.

No build tools are required; the site is plain HTML and CSS.
